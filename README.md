# Sistem Informasi Perpustakaan Sederhana

## Deskripsi

Sistem Informasi Perpustakaan Sederhana merupakan aplikasi web berbasis Laravel yang dikembangkan untuk membantu pengelolaan data buku, kategori, anggota, pengguna, serta transaksi peminjaman dan pengembalian buku.

Project ini dibuat untuk memenuhi tugas Final Project mata kuliah Pemrograman Web Framework.

## Teknologi

- PHP
- Laravel
- MySQL
- Git dan GitHub
- HTML dan CSS

## Fitur yang Direncanakan

- Login dan logout
- Manajemen pengguna dan role
- Manajemen kategori buku
- Manajemen data buku
- Manajemen data anggota
- Transaksi peminjaman dan pengembalian
- Dashboard statistik perpustakaan

## Instalasi

1. Clone repository project.
2. Masuk ke folder project.
3. Jalankan `composer install`.
4. Salin file `.env.example` menjadi `.env`.
5. Sesuaikan konfigurasi database pada file `.env`.
6. Jalankan `php artisan key:generate`.
7. Buat database MySQL sesuai konfigurasi.
8. Jalankan `php artisan migrate` setelah migration dan database siap.
9. Jalankan `php artisan serve`.
